# Calculator 🧮

**Calculator** — учебное веб-приложение для вычисления арифметических выражений, разработанное на Java с использованием Spring MVC.

## 📌 О проекте

Проект представляет собой веб-калькулятор, который позволяет пользователю вводить арифметические выражения через браузер и получать результат вычислений.

Приложение поддерживает основные арифметические операции, работу со скобками, унарные минусы и десятичные числа.

Перед вычислением выражение проходит проверку на корректность. Результаты успешных вычислений сохраняются в архив и отображаются в истории.

Проект разработан в образовательных целях для изучения Java, Spring MVC, обработки пользовательского ввода и организации веб-приложений.

## ✨ Основные возможности

- Вычисление арифметических выражений
- Поддержка сложения, вычитания, умножения и деления
- Работа с десятичными числами
- Поддержка унарного минуса
- Вычисление выражений со скобками
- Соблюдение приоритета арифметических операций
- Округление результатов до двух знаков после запятой
- Проверка корректности введённых выражений
- Обработка деления на ноль
- Сохранение истории вычислений
- Отображение предыдущих результатов в браузере

## ➕ Поддерживаемые операции

| Операция | Описание | Пример |
|---|---|---|
| `+` | Сложение | `5 + 3 = 8` |
| `-` | Вычитание | `10 - 4 = 6` |
| `*` | Умножение | `6 * 7 = 42` |
| `/` | Деление | `15 / 3 = 5` |
| `()` | Группировка выражений | `(2 + 3) * 4 = 20` |
| `-` | Унарный минус | `-5 + 2 = -3` |

### Приоритет операций

При вычислении выражений учитывается стандартный математический приоритет:

1. Вычисление выражений в скобках
2. Умножение и деление
3. Сложение и вычитание

Пример:

```text
2 + 3 * 4 = 14
```

Сначала выполняется умножение, затем сложение.

## 🏗 Архитектура проекта

Приложение построено на основе Spring MVC и разделяет ответственность между контроллером, моделью, DAO и вычислительной логикой.

### Основные компоненты

| Компонент | Назначение |
|---|---|
| `Calculator` | Выполнение арифметических вычислений |
| `Validator` | Проверка корректности выражений |
| `CalculatorController` | Обработка HTTP-запросов |
| `CalculatorDAO` | Хранение текущего результата и истории |
| `Calculation` | Модель вычисления |
| `InputDataException` | Исключение для ошибок входных данных |
| `SpringConfig` | Конфигурация Spring MVC |
| `MySpringMvcDispatcherSerlvetIntitializer` | Настройка DispatcherServlet |

## 🚀 Запуск проекта

### Требования

Для запуска приложения необходимы:

- JDK 8 или выше
- Apache Maven
- Apache Tomcat 9 или другой совместимый Servlet-контейнер
- IntelliJ IDEA или другая Java IDE

### Клонирование репозитория

```bash
git clone https://github.com/YuryShlyahov/Calculator.git
cd Calculator
```

### Сборка проекта

Для сборки приложения выполните:

```bash
mvn clean package
```

После успешной сборки Maven создаст WAR-файл:

```text
target/Calculator.war
```

### Развёртывание приложения

1. Соберите проект с помощью Maven.
2. Скопируйте `Calculator.war` в директорию `webapps` Apache Tomcat.
3. Запустите Tomcat.
4. Откройте браузер.

Приложение будет доступно по адресу:

```text
http://localhost:8080/Calculator/calculations/input
```

Порт `8080` указан по умолчанию для Apache Tomcat. Если в конфигурации используется другой порт, замените его в URL.

## 🖥 Пользовательский интерфейс

Веб-интерфейс позволяет:

- Ввести арифметическое выражение
- Отправить выражение на вычисление


## ⚠️ Валидация данных

Перед вычислением выражение проверяется на наличие ошибок.

Проверяются следующие условия:

- Пустая строка
- Наличие букв
- Отсутствие цифр
- Отсутствие арифметических операторов
- Некорректная последовательность символов
- Несколько десятичных точек в числе
- Несбалансированные скобки
- Некорректное расположение операторов относительно скобок
- Некорректные символы в начале или конце выражения

При обнаружении ошибки приложение выводит сообщение о некорректном вводе.

Также предусмотрена обработка деления на ноль.
